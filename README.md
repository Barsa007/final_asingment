# Final Project Portfolio

By: Bar Sasson

## Overview

This project contains a complete collection of academic and technical assignments focused on modern AI and data retrieval techniques. The work covers theoretical understanding, vector database implementation, Retrieval-Augmented Generation (RAG), and a final capstone chatbot application.

The repository is organized into multiple assignment folders, each demonstrating a different concept and practical implementation.

---

## Project Structure

- Assignment 1 . Theory/
  - Research and written theory work related to the course concepts.

- Assignment 2 · Coding -Vector Database/
  - Implementation and experimentation with vector-based search and embeddings.

- Assignment 3 · Coding -RAG/
  - Retrieval-Augmented Generation project using document loading, embeddings, and Q&A workflows.

- Assignment 4 · Capstone/
  - Final real-world AI application: a restaurant chatbot with database integration and app interfaces.

---

## Objectives

This final project aims to:

- Understand core AI and information retrieval concepts.
- Build practical vector database workflows.
- Implement semantic search and document-based question answering.
- Develop a conversational AI application using real data.
- Integrate frontend/backend concepts and deployment-ready configuration.

## Setup

1. Open the project folder.
2. Create and activate a virtual environment.
3. Install the required dependencies.
4. Configure environment variables such as API keys when needed.
5. Run the relevant scripts for each assignment.

Example:

```bash
cd "/Users/barsasson/Documents/Academics/final asingment"
python3 -m venv .venv
source .venv/bin/activate
pip install -r "Assignment 4 · Capstone/requirements.txt"
```

## Main Assignments

### 1. Theory Assignment
This section focuses on understanding the underlying concepts behind AI, retrieval systems, and modern language model workflows.

### 2. Vector Database Assignment
This assignment demonstrates how semantic data can be stored, searched, and retrieved using embeddings and vector similarity.

### 3. RAG Assignment
This section builds a document-based question answering system using a vector store and LLM retrieval pipeline.

### 4. Capstone Project
The final application is a restaurant chatbot that combines conversation, data access, and intelligent response generation to assist users with restaurant-related queries.
